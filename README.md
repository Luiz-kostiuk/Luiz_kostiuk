# Calculadora em Python

Projeto desenvolvido durante meus estudos de Python.

## Sobre o projeto

Uma calculadora simples desenvolvida em Python que permite ao usuário realizar operações matemáticas básicas.

O programa recebe dois números e permite escolher entre:

- Soma (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)

Também possui tratamento para operações inválidas.

## Conceitos praticados

- Variáveis
- `input()`
- `print()`
- Conversão de tipos com `int()`
- Estruturas condicionais `if`, `elif` e `else`
- Operadores matemáticos
- F-strings

## Objetivo

Este projeto faz parte da minha evolução nos estudos de programação e Python, com foco no desenvolvimento da lógica de programação e na construção de pequenos projetos práticos.
